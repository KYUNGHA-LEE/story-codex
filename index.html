1단계. 줄거리 만들기

줄거리 결과
아래 내용은 직접 고칠 수 있습니다. 고친 내용이 다음 단계에 그대로 사용됩니다.

2단계. 캐릭터 고정 명세 만들기 핵심

사용 팁 먼저 이 프롬프트로 캐릭터 참조 이미지를 1장 만들고, 이후 장면 이미지를 만들 때 그 참조 이미지를 함께 첨부하면 캐릭터 일관성이 가장 좋습니다.
캐릭터 카드
아래 원본 표를 직접 고치면 카드도 함께 바뀌고, 다음 단계에도 고친 내용이 사용됩니다.

3단계. 페이지별 원고 만들기

페이지별 원고 카드
아래 원본 표를 직접 고치면 카드도 함께 바뀌고, 다음 단계에도 고친 내용이 사용됩니다.

4단계. 장면묘사와 최종 이미지 프롬프트

2단계 캐릭터 명세와 3단계 원고를 자동으로 사용합니다. 캐릭터의 외형 명세는 토씨 하나 바꾸지 않고 그대로 복사되도록 요청합니다.

장면별 최종 이미지 프롬프트 카드
아래 원본 표를 직접 고치면 카드도 함께 바뀝니다. 카드의 복사 버튼을 누르면 화풍·크기 태그까지 포함된 최종 프롬프트가 복사됩니다.

1단계부터 4단계까지 입력한 내용과 생성 결과를 한 문서로 저장합니다.

작업 내용을 JSON 파일로 저장해 두면, 다른 컴퓨터나 브라우저에서 불러와 이어서 작업할 수 있습니다. (API 키는 저장되지 않습니다)

모든 입력과 결과는 이 컴퓨터의 브라우저에 자동 저장되어, 새로고침해도 유지됩니다.
